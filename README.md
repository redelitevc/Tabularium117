## 🛠️ Troubleshooting

### Tabularium117 Won't Start
Make sure you're running Windows 11. If you see a Windows SmartScreen warning, click "More info" and then "Run anyway" — this is normal for a new unsigned application.

### No Data Showing
Restart both Anno 117 and Tabularium117. Make sure the game is running before you launch the companion app. Also check that both applications are on the same PC (they must be on the same machine).

### Alerts Not Appearing
Check that your volume isn't muted — alerts have a sound component. You can also enable visual-only alerts in the settings menu.

### App Crashes
Delete the `tabularium_config.json` file from the same folder as the application, then restart. This resets all settings to defaults.
